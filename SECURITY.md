# Security policy

TripForge is a static site with no backend and no accounts. The main risks are a weakened Content-Security-Policy, injected third-party code, or a prompt that leads an AI to ask for or publish personal data.

## Reporting a vulnerability

Please report privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a public issue.

Include what you found, how to reproduce it, and the impact. You will get a reply within a week.

## Supported versions

Only the live site and the `main` branch are supported.
