# Code of Conduct

TripForge follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be respectful, assume good intent, and accept feedback gracefully. Harassment, insults and personal attacks are not tolerated in issues, pull requests or anywhere else in the project.

## Reporting

If someone is behaving in a way that breaks this code, contact the maintainer, [Dan Lemon](https://danlemon.com), privately. Reports are handled confidentially. The maintainer may remove comments, close threads or block people who break the code.
